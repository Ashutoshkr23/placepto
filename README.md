# Placepto

Placepto is a playful learning platform for school students. This repository is the initial visual foundation with a static, responsive homepage.

## Current stage

30 Days Maths Foundation and School Book Games are visual previews only. Gameplay architecture, Firebase backend features, and student accounts will be designed in later phases.

## Stack

Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, and the Firebase SDK (prepared only).

## Local development

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` when Firebase configuration is available. The app runs safely without Firebase environment values.

## Checks

```bash
npm run lint
npm run build
```
